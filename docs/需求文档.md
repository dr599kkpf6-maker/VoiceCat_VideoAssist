# 视频助手需求文档

带一个小主窗口的 Windows 工具。本版只控制哔哩哔哩桌面客户端。关联说明见 [技术设计.md](技术设计.md)。

## 界面

### 窗口布局

一个小主窗口，标题是「视频助手猫师傅」，启动后直接显示。有托盘图标：关闭窗口最小化到托盘，从托盘菜单退出。

- 左侧竖排三个标签：哔哩哔哩、抖音、红果。默认选中哔哩哔哩。
- 抖音、红果本期不做：标签保留，内容区盖灰色蒙层，点击不生效。
- 右侧是当前标签的控制页面。

### 控制页面

检查区在左，右上角从左到右是声波线、启动计时、【启动控制器】。声波线是一条细线，用来看现在能不能正常听到声音。计时格式 `HH:MM:SS`，默认 `00:00:00`。窗口上不放打开配置。执行结果不在窗口展示：成功以哔哩哔哩的实际反应为准，失败原因记入日志。

按钮默认处于未启动。点击后逐项检查四项必要项，任一不通过即启动失败：

1. 哔哩哔哩客户端已通过调试端口启动
2. 麦克风设备已识别
3. 麦克风权限可用
4. 语音识别模型已下载

每项不通过时，右侧显示对应的修复按钮：

| 检查项 | 修复按钮 | 按钮做的事 |
| --- | --- | --- |
| 哔哩哔哩客户端已通过调试端口启动 | 【重启哔哩哔哩】 | 客户端在运行时，先确认再关闭，然后重新打开；没在运行时直接打开 |
| 麦克风设备已识别 | 【重新检测】 | 重新识别麦克风设备 |
| 麦克风权限可用 | 【打开权限设置】 | 打开系统麦克风权限设置页，用户开启后自动重新检查 |
| 语音识别模型已下载 | 【重新下载】 | 重新下载模型文件 |

页面状态：

| 状态 | 显示 | 声波线 | 计时 | 检查区 |
| --- | --- | --- | --- | --- |
| 未启动（默认） | 按钮【启动控制器】 | 不显示 | `00:00:00` | 空白 |
| 检查中 | 逐项出现检查项 | 不显示 | `00:00:00` | 正在检查的项显示检查中；通过打钩，不通过打叉 |
| 启动失败 | 【启动失败】，右侧是重试标识 | 不显示 | `00:00:00` | 保留各项检查结果 |
| 已启动 | 【已启动】，再次点击按钮即断开 | 显示，按听到的声音大小起伏 | 从进入已启动起按秒累加 | 必要项保持打钩 |

必要项全部通过即显示【已启动】。修复按钮完成后只重新检查自己那一项。


## 交互

### 启动与断开

- 点击【启动控制器】：逐项检查。全部通过则进入已启动，开始监听，计时从 `00:00:00` 开始按秒累加，并在计时左侧显示声波线。
- 任一必要项不通过：检查完毕后显示【启动失败】。点击右侧重试标识，重新逐项检查。检查中和启动失败都不显示声波线，计时保持 `00:00:00`。
- 已启动时再次点击按钮：断开。停止监听、放开麦克风，回到未启动，检查区恢复空白，声波线消失，计时清空为 `00:00:00`。
- 抖音、红果标签点击不生效。
- 关闭主窗口：最小化到托盘，不退出。单击托盘图标，或托盘菜单的「显示主窗口」，重新打开窗口。
- 托盘菜单：显示主窗口、启动控制器（已启动时为断开）、退出。菜单里的启动/断开与窗口上的【启动控制器】按钮是同一个动作，声波线和计时同样出现或清空。
- 托盘菜单的「退出」才结束程序。已启动时先断开再退出。
- 【重启哔哩哔哩】：客户端正在运行时，先弹确认「将关闭当前哔哩哔哩并重新打开」，确认后关闭并重新打开；没在运行时不弹确认，直接打开。完成后重新检查该项。重新打开的方式自带助手读取页面所需的通道。

### 语音控制

工具名字是猫师傅。唤醒词固定为「猫师傅」，不能改。每一条指令都必须带上「猫师傅」。可以连着说，例如「猫师傅，暂停」。

一条指令先说「猫师傅」，再说这一条要做的事，停下来即结束。同一句里有多条指令时，每条都要各自带「猫师傅」，例如「猫师傅，暂停。猫师傅，下一个」。没带「猫师傅」的那条不执行。只说指令、没说「猫师傅」时，不触发任何操作。没听清时不做操作，也不追问。

说法不必一字不差。下表每一句都要带「猫师傅」。

| 说法 | 结果 |
| --- | --- |
| 猫师傅，暂停 / 猫师傅，播放 / 猫师傅，继续 | 播放与暂停切换 |
| 猫师傅，全屏 | 全屏切换 |
| 猫师傅，大声 / 猫师傅，音量加 | 音量增大 |
| 猫师傅，小声 / 猫师傅，音量减 | 音量减小 |
| 猫师傅，静音 | 静音切换 |
| 猫师傅，切到直播 / 猫师傅，切到推荐 / 猫师傅，切到热门 / 猫师傅，切到追番 / 猫师傅，切到影视 | 回到主页面，打开主页面标签栏上的这个标签 |
| 猫师傅，我要看一天极限逛吃汕头 | 在当前已经显示出来的视频卡片里，按标题模糊匹配后打开这一条 |
| 猫师傅，我要看右边的日食记的死磕2个月，终于做出封神牛肉视频 | 在当前视频右边菜单栏里，按标题模糊匹配后打开对应视频 |
| 猫师傅，下一个 / 猫师傅，下一条 / 猫师傅，我要看下一个视频 | 打开当前这份列表里的下一项 |
| 猫师傅，上一个 / 猫师傅，上一条 / 猫师傅，我要看上一个视频 | 打开当前这份列表里的上一项 |
| 猫师傅，返回 | 返回上一个页面 |
| 猫师傅，返回主界面 | 返回主页面 |

卡片是竖排还是平铺，都按已经显示出来的标题来认。「猫师傅，我要看下一个视频」打开相邻下一项。「猫师傅，切到直播」打开主页面标签栏上的直播。

「我要看右边的……视频」只认当前视频右边菜单栏里的标题，不拿它去对主页面上的卡片。用户看视频时，说出的名称不必和视频名逐字相同，按模糊匹配打开最接近的一条，不要求整句标题完全一致。只说标题里的一部分也可以，例如「猫师傅，我要看右边的封神牛肉」对上「日食记的死磕2个月，终于做出封神牛肉」。主页面上的视频卡片同样模糊匹配。「猫师傅，返回主界面」整句先认，不按「猫师傅，返回」只退一页。

播放和暂停是两个说法，对应同一次切换。已经暂停时再说「猫师傅，暂停」，会开始播放。说反了再喊一次。

## 逻辑

1. 点击【启动控制器】后逐项检查四项必要项。全部通过才进入已启动，开始监听。任一不通过即启动失败，该项右侧显示修复按钮。
2. 只有已启动时才读麦克风。未启动、启动失败、断开之后都不读麦克风。
3. 窗口最小化到托盘后，已启动的监听不受影响，计时继续累加。重新打开窗口时，声波线仍按当前听到的声音显示。
4. 计时在声波线右侧、【启动控制器】左侧，格式 `HH:MM:SS`，表示这一次持续已启动的时长。小时不按 24 进位归零。未启动、检查中、启动失败都显示 `00:00:00`。进入已启动后从 0 开始按秒累加。窗口上的断开、托盘菜单的断开、退出前的断开，都把计时清空为 `00:00:00`。
5. 声波线在计时左侧，是一条细线。未启动、检查中、启动失败、断开之后都不显示。进入已启动后才显示。安静时保持细线，听到声音后按声音大小起伏：声音越大，波纹越高。它只表示麦克风正在听到声音，不表示某条指令已经执行。
6. 工具名字是猫师傅。唤醒词固定为「猫师傅」，不能改。每一条指令都必须带上「猫师傅」。没带、没听清，都不做操作，也不追问。同一句里的多条指令各自都要带。
7. 播放、暂停、全屏、音量：找到进程 `哔哩哔哩.exe` 的主窗口，叫到前台，并确认当前前台仍是哔哩哔哩，再发送对应按键。
8. 换标签、按标题打开、右边菜单按标题打开、返回、返回主界面、上一项和下一项：读当前已经画出来的页面再执行。主页面标签只有直播、推荐、热门、追番、影视。切到其中某一个时，先回到主页面，再打开标签栏上的这个标签。
9. 按标题打开和右边菜单按标题打开都用模糊匹配，不要求与视频名全字匹配。只在当前该认的已显示标题里，打开最接近的一条。对不上，或前两名太接近：不打开，听到的句子和最接近的标题记入日志。
10. 上一项、下一项只在包含当前正在看的那份已显示列表里移动。页面上没有相邻项就停止，原因记入日志。
11. 主页面标签栏上没有这个标签，包括被收进「更多」里的：不切换，原因记入日志。没有上一个页面时，返回停止，原因记入日志。已经在主页面时，返回主界面停在主页面。
12. 已启动后哔哩哔哩被关掉，或窗口没能置前：不按键，也不自行启动客户端，原因记入日志。
13. 页面读不到时，播放、暂停、全屏、音量仍按第 7 步做。换标签、按标题打开、右边菜单按标题打开、返回、返回主界面、上一项和下一项停止，原因记入日志。不自行关闭已经打开的哔哩哔哩。
14. 【重启哔哩哔哩】是唯一会动客户端进程的动作：客户端在运行时必须先弹确认，确认后助手关闭并重新打开；没在运行时直接打开。重新打开自带助手读取页面所需的通道。
15. 按键只发给哔哩哔哩。焦点若在客户端的搜索框或弹幕框里，暂停对应的按键会进入输入框。
16. 语音只在本机识别，不录音，不上传。

## 后续
