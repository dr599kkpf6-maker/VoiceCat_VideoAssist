# 视频助手需求文档

带一个小主窗口的 Windows 工具。本版只控制已经打开的哔哩哔哩桌面客户端。关联说明见 [技术设计.md](技术设计.md)。

## 界面

一个小主窗口，启动后直接显示。没有托盘图标，关闭窗口就是退出。

窗口上固定这些内容：

- 状态：正在监听，或已暂停
- 最近一次结果：等待命令、已执行、没听清、没找到哔哩哔哩或没能置前
- 当前能说的唤醒词和命令
- 按钮「暂停监听」。暂停后按钮变成「继续监听」
- 按钮「打开配置」

听到命令后，窗口上的结果文字会变，同时用三声很短的提示音区分，不用语音回话：

| 提示音 | 窗口结果 | 含义 |
| --- | --- | --- |
| 高而短 | 已执行 | 哔哩哔哩已按命令处理 |
| 中而短 | 没听清 | 唤醒后没有听清命令 |
| 低而稍长 | 没找到哔哩哔哩或没能置前 | 没按键 |

麦克风不可用时，状态改成「麦克风不可用」。

## 交互

先说唤醒词「助手」，再说命令。唤醒词可以在配置里改。唤醒后约 3 秒内有效，超时播放「没听清」，不做操作，也不追问。

没先说唤醒词时，说话不触发任何操作。

| 说法 | 结果 |
| --- | --- |
| 播放、继续 | 播放/暂停切换 |
| 暂停 | 同上，也是播放/暂停切换 |
| 下一个、下一条、下一个视频 | 多 P 下一条 |
| 上一个、上一条 | 多 P 上一条 |
| 哔哩哔哩、打开哔哩哔哩、切到哔哩哔哩 | 只把哔哩哔哩叫到前台 |

播放和暂停是两个说法，对应客户端里的同一个空格。说反了再喊一次。

上一条、下一条对应客户端的 `[` 和 `]`，只在多分 P 里切换。单集视频没有「下一个推荐」的快捷键，喊了也不会去点推荐栏。

## 逻辑

1. 找到进程 `哔哩哔哩.exe` 的主窗口，叫到前台。
2. 确认当前前台进程仍是哔哩哔哩，再向它发送对应按键。
3. 「切到哔哩哔哩」只做到第 2 步之前，不按播放键。
4. 窗口没开，或没能置前：播放拒绝提示音，不按键，也不启动客户端。
5. 按键不会发到聊天、文档或其他程序。
6. 语音只在本机识别，不录音，不上传。
7. 暂停监听后不再读麦克风。继续监听后恢复。
8. 关闭主窗口即退出，并停止听麦克风。
