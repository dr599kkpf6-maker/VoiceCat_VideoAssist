# 视频助手功能说明

带一个小主窗口的 Windows 工具。本版只控制哔哩哔哩桌面客户端。芒果TV的说法写在后面，标签仍锁着，本版不执行。关联说明见 [技术设计.md](技术设计.md)。

## 界面

### 窗口布局

一个小主窗口，标题是「视频助手猫师傅」，启动后直接显示。本版没有托盘。点窗口关闭就是结束助手，监听一起停。主区域右下角有浅色水印「@作者：羊师傅」。

- 左侧竖排三个标签：哔哩哔哩、芒果TV、红果。默认选中哔哩哔哩。
- 芒果TV、红果标签都先锁着，点击不生效。芒果TV要做的语音写在文末，红果本期不做。
- 右侧是当前标签的控制页面。

### 控制页面

右上角是启动计时和【启动控制器】。未启动时，按钮下面的主区域固定显示软件说明和操作指引。说明只有一句：「猫师傅」启动后可以语音控制视频客户端~解放双手！边吃边看！操作指引里的说法和下面这张表是同一套，例如打开视频说「猫师傅，我要看舒服了」，全屏说「猫师傅，全屏」。

点击【启动控制器】后，上方玻璃栏向下拉长。检测项出现在拉长的玻璃栏里，排在识别出的语音字幕下面。玻璃栏底部有向上箭头，点击后收起检测项，玻璃栏缩短；收起后箭头改为向下，点击再展开。软件说明和操作指引留在主区域，不随检测项换走。

声波线放在左侧应用栏和计时之间。声波线是一条细线，用来看现在能不能正常听到声音。声波线下有一行小字幕，只显示带唤醒的那一句原文，例如「猫师傅，我要看舒服了」「小猫，返回主页」。唤醒包括「猫师傅」，以及听成的「高师傅」「高师普」「毛师傅」「喵师傅」「老师傅」，还有「小猫」「猫猫」。没带唤醒不显示，也不做整段转写。断开后字幕清空。计时格式 `HH:MM:SS`，默认 `00:00:00`。窗口上不放打开配置。执行结果不在窗口展示：成功以哔哩哔哩的实际反应为准，失败原因记入日志。

按钮默认处于未启动。点击后逐项检查四项必要项，任一不通过即启动失败：

1. 哔哩哔哩客户端已通过调试端口启动
2. 麦克风设备已识别
3. 麦克风权限可用
4. 语音识别模型已下载

每项不通过时，右侧显示对应的修复按钮：

| 检查项 | 修复按钮 | 按钮做的事 |
| --- | --- | --- |
| 哔哩哔哩客户端已通过调试端口启动 | 【重启哔哩哔哩】 | 客户端在运行时，先确认再关闭，然后重新打开；没在运行时直接打开 |
| 麦克风设备已识别 | 【重新检测】 | 重新识别麦克风设备 |
| 麦克风权限可用 | 【打开权限设置】 | 打开系统麦克风权限设置页，用户开启后自动重新检查 |
| 语音识别模型已下载 | 【重新下载】 | 重新下载模型文件 |

页面状态：

| 状态 | 显示 | 声波线 | 计时 | 检查区 | 主区域 |
| --- | --- | --- | --- | --- | --- |
| 未启动（默认） | 按钮【启动控制器】 | 不显示 | `00:00:00` | 不显示，玻璃栏保持短 | 软件说明和操作指引 |
| 检查中 | 玻璃栏拉长，逐项出现检查项 | 不显示 | `00:00:00` | 在语音字幕下方；可收起、可展开 | 软件说明和操作指引 |
| 启动失败 | 【启动失败】，右侧是重试标识 | 不显示 | `00:00:00` | 留在拉长的玻璃栏里，保留各项结果 | 软件说明和操作指引 |
| 已启动 | 【已启动】，再次点击按钮即断开 | 显示，按听到的声音大小起伏 | 从进入已启动起按秒累加 | 必要项保持打钩，仍在玻璃栏里 | 软件说明和操作指引 |

必要项全部通过即显示【已启动】。修复按钮完成后只重新检查自己那一项。按钮本身用颜色区分：未启动是紫色，启动中是蓝粉色来回变换的极光并且小字变成「启动中」，启动失败是玫瑰色，已启动是浅粉色和浅紫色的流光。


## 交互

### 启动与断开

- 点击【启动控制器】：逐项检查。全部通过则进入已启动，开始监听，计时从 `00:00:00` 开始按秒累加，并在左侧应用栏和计时之间显示声波线。
- 任一必要项不通过：检查完毕后显示【启动失败】。点击右侧重试标识，重新逐项检查。检查中和启动失败都不显示声波线，计时保持 `00:00:00`。
- 已启动时再次点击按钮：断开。停止监听、放开麦克风，回到未启动，玻璃栏缩回短栏，检测项收起，声波线消失，计时清空为 `00:00:00`。软件说明和操作指引仍留在主区域。
- 芒果TV、红果标签点击不生效。
- 关闭主窗口：结束助手。已启动时监听一起停。本版没有托盘，也没有「显示主窗口」菜单。
- 【重启哔哩哔哩】：客户端正在运行时，先弹确认「将关闭当前哔哩哔哩并重新打开」，确认后关闭并重新打开；没在运行时不弹确认，直接打开。完成后重新检查该项。重新打开的方式自带助手读取页面所需的通道。

### 语音控制

工具名字是猫师傅。唤醒不必字正腔圆。「猫师傅」说得含糊、听成「高师傅」「高师普」「毛师傅」「喵师傅」「猫师父」「老师傅」「哦师傅」，或者说短一点的「小猫」「猫猫」，都算唤醒。句子里只要听出「师傅」，也按唤醒算。每一条指令都要带上这类称呼。可以连着说，例如「猫师傅，暂停」。

一条指令先说唤醒，再说这一条要做的事，停下来即结束。同一句里有多条指令时，每条都要各自带唤醒，例如「猫师傅，暂停。猫师傅，下一个」。没带唤醒的那条不执行。只说指令、没说唤醒时，不触发任何操作，字幕也不更新。没听清时不做操作，也不追问。转写只在听到唤醒之后才做，不一直转写。

操作指引里每条都写了一句原话。下表第一句和指引相同，斜杠后面是同样生效的说法。换成「小猫」「猫猫」「老师傅」，或听成「高师傅」「高师普」，也一样。

| 说法 | 结果 |
| --- | --- |
| 猫师傅，暂停 / 猫师傅，播放 / 猫师傅，继续 | 播放与暂停切换 |
| 猫师傅，全屏 / 猫师傅，放大全屏 | 全屏切换 |
| 猫师傅，退出全屏 / 猫师傅，窗口观看 | 只在已经全屏时退出，改成窗口观看。已经是窗口时不再按全屏键 |
| 猫师傅，大声 / 猫师傅，音量加 | 音量增大 |
| 猫师傅，小声 / 猫师傅，音量减 | 音量减小 |
| 猫师傅，静音 | 静音切换 |
| 猫师傅，切到直播 / 猫师傅，切到热门栏 / 猫师傅，切换直播栏目 / 猫师傅，切到直播南目 / 猫师傅，切到推荐 / 猫师傅，切到热门 / 猫师傅，切到追番 / 猫师傅，切到影视 | 离开正在看的视频，回到主页面，打开主页面标签栏上的这个标签。说快了、重复一个「切」、或中间夹一个气声，仍然算切栏目 |
| 猫师傅，我要看【主播名称】直播 / 猫师傅，我要看老饭骨的直播 / 猫师傅，打开老饭骨直播 | 只在直播页面打开对应直播。先匹配「我关注的主播」里正在直播的主播，以及这些主播名下已经显示出来的直播；对不上，再匹配页面里其余直播的标题或主播名 |
| 猫师傅，搜索【视频名称】 / 猫师傅，搜索生命奇观 / 猫师傅，搜索生命奇观视频 | 把识别出的名称填进哔哩哔哩顶部搜索框，并打开搜索页。末尾单独的「视频」不放进搜索框，名称开头多听进去的「搜索」也不放进去 |
| 猫师傅，切换1080P / 猫师傅，切换720P / 猫师傅，切换到1080P / 猫师傅，一零八零 | 把正在播放的视频切到这一档清晰度。1080P 点「1080P 高清」，720P 点「720P 准高清」 |
| 猫师傅，我要看舒服了 | 在当前已经显示出来的视频卡片里，按标题打开。片名照卡片上的字说，很短也可以 |
| 猫师傅，我要看右边的封神牛肉 | 只在当前视频右边菜单栏里，按标题打开 |
| 猫师傅，下一个 / 猫师傅，下一条 | 打开当前这份列表里的下一项 |
| 猫师傅，上一个 / 猫师傅，上一条 | 打开当前这份列表里的上一项 |
| 猫师傅，返回 | 返回上一个页面 |
| 猫师傅，返回主页 / 猫师傅，返回主界面 / 猫师傅，返回主页面 / 猫师傅，回到主页面 / 猫师傅，返回首页 | 回到推荐首页。人在搜索、直播、热门这些页时也会回去；播放页还开着，就先点「回到主界面」 |
| 猫师傅，刷新 / 猫师傅，刷新一下 / 猫师傅，刷新当前页面 | 刷新当前正在看的这个窗口 |
| 猫师傅，下滑 / 猫师傅，往下滚 | 当前列表向下滚动大约三分之二页 |
| 猫师傅，上滑 / 猫师傅，往上滚 | 当前列表向上滚动大约三分之二页 |
| 猫师傅，关闭当前视频 / 猫师傅，关掉当前视频 | 关闭当前正在看的视频窗口。哔哩哔哩主窗口留着，不退出客户端 |

卡片是竖排还是平铺，都按已经显示出来的标题来认，作者名和日期不拼进片名。播放量、弹幕数、时长不当成标题。例如「475.8万 2872 20:33」不拿去和用户说的片名比对。标题只有「舒服了」时，就认「舒服了」，不拿「杨齐家 · 10-23」去比。「猫师傅，我要看下一个」打开相邻下一项，不拿「下一个」当标题。「猫师傅，切到直播」「猫师傅，切换直播栏目」和听成「猫师傅，切到直播南目」都打开主页面标签栏上的直播，不拿这句话当片名去搜索。

「猫师傅，搜索生命奇观」会把「生命奇观」填进搜索框再进入搜索结果，不把「猫师傅」和「搜索」这两个字放进去。说成「猫师傅，搜索生命奇观视频」也一样。名称开头如果又听进一个「搜索」或「搜」，例如听成「搜搜索生命奇观」，仍然只填「生命奇观」。它和「我要看生命奇观」不是一回事：搜索是打开全站搜索页，我要看是在当前页面已经显示的卡片里打开。

已经在搜索结果的综合页时，「猫师傅，我要看XX视频」先匹配综合结果上方的影视作品，包括电影、番剧、电视剧这些卡片。对上就打开这一部。好几部太接近时不打开。对不上，再按当前页面里已经显示的视频卡片打开。这个优先顺序不写进操作指引，说法仍是「我要看」。

「猫师傅，切换1080P」和「猫师傅，切换720P」只改正在播放的视频清晰度。1080P 对应菜单里的「1080P 高清」，不含 60 帧，也不含 4K。720P 对应「720P 准高清」。也可以说「切换到1080P」「一零八零」「七二零」。已经是这一档就不改。没有正在播放的视频，或菜单里没有这一档，都不操作，原因记入日志。

「猫师傅，我要看【主播名称】直播」只在已经打开的直播页面里生效，不负责先切到直播栏目。它和「切到直播」不是一回事。直播页上方是「我关注的主播」，下面是页面里的直播。先在关注的主播里匹配：主播名对上，就打开这位主播正在播的直播；这位主播的直播标题已经显示在页面上，标题对上也打开这一条。关注里对不上，再在页面其余直播里按标题或主播名打开最接近的一条。也可以说「我要看老饭骨的直播」「打开老饭骨直播」。不在直播页面时不打开，原因记入日志。对不上，或前两名太接近，也不打开。

「猫师傅，我要看右边的封神牛肉」只认当前视频右边菜单栏里的标题，不拿它去对主页面上的卡片。说出的名称不必和视频名逐字相同，按模糊匹配打开最接近的一条。只说标题里的一部分也可以，例如「封神牛肉」对上「日食记的死磕2个月，终于做出封神牛肉」。主页面上的视频卡片同样模糊匹配。

返回主页面先按整句认，不按「返回」只退一页。认这些说法：「返回主界面」「返回主页面」「返回主页」「回到主页面」「返回首页」，中间多说一个「回」也可以，例如「返回回主界面」。正在看的视频在播放页，主页面是另一个还开着的页面。主页面还开着，也不算已经回到首页：播放页还在就点播放页上的「回到主界面」，主窗口如果停在搜索、直播、热门或其他栏目，再回到推荐首页，并把主窗口叫到前台。已经在推荐首页时，停在这一页。单独的「返回」只退上一个页面。

「猫师傅，刷新」「猫师傅，刷新一下」「猫师傅，刷新当前页面」刷新当前前台的哔哩哔哩窗口。正在看视频时刷新播放页，停在主窗口时刷新主窗口。

「猫师傅，下滑」「猫师傅，往下滚」把当前列表向下滚动大约三分之二页。「猫师傅，上滑」「猫师傅，往上滚」向上滚同样的距离。已经到顶或到底时不再滚，原因记入日志。搜索结果页滚的是结果列表。

「关闭当前视频」只关播放窗口，不关哔哩哔哩主窗口，也不结束客户端。也可以说「关掉当前视频」「关闭这个视频」「关闭视频窗口」。没有正在播放的视频时不操作，原因记入日志。它和「返回主页面」不是一回事：返回是点播放页上的「回到主界面」，关闭是点播放窗口右上角的关闭。

播放和暂停是两个说法，对应同一次切换。已经暂停时再说「猫师傅，暂停」，会开始播放。说反了再喊一次。

「猫师傅，全屏」和「猫师傅，放大全屏」是同一次切换，可能进入全屏，也可能从全屏退出来。「猫师傅，退出全屏」不是这次切换：只在播放页已经全屏时退出，回到窗口观看。已经是窗口、看不出是不是全屏、或没有正在播放的视频，都不按全屏键，原因记入日志。也可以说「窗口观看」。

## 逻辑

1. 点击【启动控制器】后逐项检查四项必要项。全部通过才进入已启动，开始监听。任一不通过即启动失败，该项右侧显示修复按钮。
2. 只有已启动时才读麦克风。未启动、启动失败、断开之后都不读麦克风。
3. 本版没有托盘。关闭窗口即结束助手，监听停止。窗口还开着时，最小化到任务栏不影响已启动的监听，计时继续累加。
4. 计时在声波线右侧、【启动控制器】左侧，格式 `HH:MM:SS`，表示这一次持续已启动的时长。小时不按 24 进位归零。未启动、检查中、启动失败都显示 `00:00:00`。进入已启动后从 0 开始按秒累加。窗口上的断开把计时清空为 `00:00:00`。关闭窗口则助手结束。
5. 声波线在左侧应用栏和计时之间，是一条细线。未启动、检查中、启动失败、断开之后都不显示。进入已启动后才显示。安静时保持细线，听到声音后按声音大小起伏：声音越大，波纹越高。它只表示麦克风正在听到声音，不表示某条指令已经执行。声波线下的小字幕只在听出唤醒后更新，显示的是听出来的那一句原文。没带唤醒不更新字幕，也不做整段转写。断开后字幕清空。
6. 工具名字是猫师傅。唤醒认「猫师傅」，也认听起来接近的「高师傅」「高师普」「毛师傅」「喵师傅」「猫师父」「老师傅」「哦师傅」，以及「小猫」「猫猫」。句子里听出「师傅」也算唤醒，不要求字正腔圆。没带这类称呼、没听清，都不做操作，也不追问，字幕也不更新。同一句里的多条指令各自都要带。暂停、播放、继续允许多一两个口头字，例如「在暂停」「继续播放」「暂停视频」，仍按播放暂停执行，不拿去对视频标题。全屏认句子里的「全屏」，「全屏」和「放大全屏」都是全屏切换。「退出全屏」「窗口观看」只退出全屏，不拿去切换进全屏。切栏目认「切到」「切换」「切换到」，只说「切到直播」也可以，说「切到热门栏」「切到热门栏目」也一样，不必把「栏目」说全。说快了会听成「切切到」「切刀」「现在到」，或在「切」和「到」中间夹一个气声字，例如「切街到影视」，仍然切到对应栏目，不拿去对视频标题。标签名后面可以带「栏目」或「频道」，例如「切到到热门」「切换直播栏目」。n、l 不分时「栏目」会说成「南目」，例如「切到直播南目」，仍按切到直播执行。推荐、热门、追番、影视同样。返回主页面认「返回主页」「返回主界面」「返回主页面」「回到主页面」「返回首页」，不在推荐首页时会回到推荐首页。「刷新」「刷新一下」「刷新当前页面」刷新当前窗口。「下滑」「往下滚」和「上滑」「往上滚」按大约三分之二页滚动当前列表。关闭当前视频认「关闭当前视频」「关掉当前视频」「关闭这个视频」「关闭视频窗口」，只关播放窗口。按标题打开时，片名按卡片标题本身认，短标题也认，作者名和日期不拿来比对。直播页面上的「我要看某某直播」先认关注的主播，再认页面里的直播，不拿去切栏目，也不拿去对普通视频卡片。「搜索某某」把名称填进搜索框并打开搜索页，不拿去对当前卡片，也不把「搜索」本身打进搜索框。综合搜索结果页上的「我要看」先认上方影视作品。「切换1080P」「切换720P」只改正在播放的清晰度。
7. 播放、暂停、全屏、音量：找到进程 `哔哩哔哩.exe` 的主窗口，叫到前台，并确认当前前台仍是哔哩哔哩，再发送对应按键。退出全屏先看播放页是不是已经全屏，是才发送全屏对应的按键；不是就不按。
8. 换标签、按标题打开、右边菜单按标题打开、在直播页面按主播或直播名打开、搜索、切换清晰度、返回、返回主页面、刷新、滚动列表、关闭当前视频、上一项和下一项：读当前已经画出来的页面再执行。搜索时把识别出的名称写入主窗口顶部搜索框，并打开搜索页，不写入「搜索」这两个字。在搜索结果的综合页按标题打开时，先在综合结果上方的影视作品里匹配，对上就打开这一部；对不上，再在已经显示的视频卡片里匹配。切换清晰度时，在正在播放的视频里点清晰度菜单：1080P 打开「1080P 高清」，720P 打开「720P 准高清」，不点 60 帧和 4K。没有正在播放的视频，或菜单里没有这一档，不操作，原因记入日志。正在看的视频在播放页，主页面是另一个页面；主页面还开着，也不代表用户已经回到主页面。返回主页面时，播放页还在就点播放页上的「回到主界面」；主窗口不在推荐首页时再回到推荐首页，并把主窗口叫到前台。刷新当前前台窗口。滚动时，当前列表按大约三分之二页移动，搜索结果页滚的是结果列表。关闭当前视频时，点播放窗口右上角的关闭，只关掉这个视频窗口，主窗口保持打开，也不结束哔哩哔哩进程。没有播放页时不关闭任何窗口，原因记入日志。主页面标签只有直播、推荐、热门、追番、影视，都在主页面顶部标签栏。切到其中某一个时，先离开播放页回到主页面，再点这个标签。不要去点视频卡片上单独出现的「直播」字样。
9. 按标题打开、右边菜单按标题打开、直播页面按主播或直播名打开，都用模糊匹配，不要求与名字全字匹配。直播页面先只在关注的主播和这些主播名下的直播里挑；这里对不上，再只在页面其余直播里挑。对不上，或前两名太接近：不打开，听到的句子和最接近的标题记入日志。
10. 上一项、下一项只在包含当前正在看的那份已显示列表里移动。页面上没有相邻项就停止，原因记入日志。
11. 主页面标签栏上没有这个标签，包括被收进「更多」里的：不切换，原因记入日志。没有上一个页面时，返回停止，原因记入日志。已经在推荐首页时，返回主页面停在推荐首页。列表已经到顶或到底时，滚动停止，原因记入日志。
12. 已启动后哔哩哔哩被关掉，或窗口没能置前：不按键，也不自行启动客户端，原因记入日志。
13. 页面读不到时，播放、暂停、全屏、音量仍按第 7 步做。退出全屏读不到播放页时停止，避免没在全屏时又被按进全屏。换标签、按标题打开、右边菜单按标题打开、在直播页面打开直播、搜索、切换清晰度、返回、返回主页面、刷新、滚动列表、关闭当前视频、上一项和下一项停止，原因记入日志。不自行关闭已经打开的哔哩哔哩。
14. 【重启哔哩哔哩】是唯一会动客户端进程的动作：客户端在运行时必须先弹确认，确认后助手关闭并重新打开；没在运行时直接打开。重新打开自带助手读取页面所需的通道。
15. 按键只发给哔哩哔哩。焦点若在客户端的搜索框或弹幕框里，暂停对应的按键会进入输入框。
16. 语音只在本机识别，不录音，不上传。

## 芒果TV控制器

这一节只写要做什么，本版不写代码，标签继续锁着，喊了也不执行。唤醒和哔哩哔哩是同一套：猫师傅，以及听成的高师傅、高师普、毛师傅、喵师傅、老师傅、小猫、猫猫。没带这类称呼就不做。双手被占着时，资深用户要能把现在用鼠标完成的追剧动作说出来。

芒果TV电脑版的界面和哔哩哔哩不是同一套。左侧是栏目：首页、电影、电视剧、综艺、动漫、少儿、纪录片、直播、本地播放。顶部是搜索框、登录和个人中心。中间是推荐、热播和专题。点进一部片子后是播放页：进度条附近有播放、音量、倍速、弹幕、清晰度和全屏；剧集和综艺的集数排在播放页旁边，可以直接点第几集。清晰度用芒果自己的档：蓝光、1080P、超清、高清、720P、标清，不是哔哩哔哩那套「1080P 高清 / 720P 准高清」。全屏键会来回切换；退出全屏用只退不进的方式，已经是窗口就不再按全屏键。直播栏目里是湖南卫视这类频道，不是哔哩哔哩那种关注的主播头像。

下表第一句是准备放进芒果TV操作指引的原话。斜杠后面是同样生效的说法。

| 说法 | 结果 |
| --- | --- |
| 猫师傅，暂停 / 猫师傅，播放 / 猫师傅，继续 | 播放与暂停切换 |
| 猫师傅，全屏 / 猫师傅，放大全屏 | 全屏切换 |
| 猫师傅，退出全屏 / 猫师傅，窗口观看 | 只在已经全屏时退出，改成窗口观看 |
| 猫师傅，大声 / 猫师傅，音量加 | 音量增大 |
| 猫师傅，小声 / 猫师傅，音量减 | 音量减小 |
| 猫师傅，静音 | 静音切换 |
| 猫师傅，切到综艺 / 猫师傅，切到电视剧 / 猫师傅，切到电影 / 猫师傅，切到动漫 / 猫师傅，切到少儿 / 猫师傅，切到纪录片 / 猫师傅，切到直播 / 猫师傅，切到首页 / 猫师傅，切到本地播放 | 点左侧这个栏目。说快了、听成「南目」，仍算切栏目，不拿去对片名 |

搜索和「我要看」仍是两件事。搜索打开全站结果；我要看只认眼前已经画出来的标题。综艺、电视剧的「下一集」认的是选集，不是首页推荐流里的下一条。直播先要自己切到直播栏目，再说频道名。对不上、前两名太接近、页面读不到，都不操作，原因记入日志。

这一节不做：登录、开通会员、下载缓存、发弹幕、投屏、跳过片头的设置、改下载目录。本地播放只切到那个栏目，不按文件路径去找电脑里的视频。
